Real Estate Data Analysis & Risk Assessment

Project Overview

This project analyzes real estate project data using Microsoft Excel to evaluate sales performance, unsold inventory, inventory risk, and financial indicators.

The workbook uses Excel formulas, risk classifications, and scenario-based analysis to identify projects that may require attention and to support data-driven decision-making.
