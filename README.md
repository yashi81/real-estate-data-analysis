# Real Estate Data Analysis

## Project Overview

This project analyzes real estate data using Microsoft Excel to identify trends and insights related to property prices, locations, and other property characteristics.

## Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Data Analysis
- Data Visualization

## Key Work

- Cleaned and organized the real estate dataset
- Used Excel formulas for data analysis
- Created Pivot Tables to summarize the data
- Analyzed property-related trends
- Created visualizations to present key findings

## Project File

- `Real_Estate_Analysis.xlsx` — Excel workbook containing the complete analysis

## Objective

The objective of this project is to analyze real estate data and extract meaningful insights that can support better understanding and decision-making.
